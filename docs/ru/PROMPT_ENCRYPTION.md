# Шифрование Промптов - Защитите ваши промпты в OpenAI/Anthropic

## Зачем?

Когда вы отправляете промпты в OpenAI или Anthropic, они могут видеть точно, что вы написали. С Шифрованием Промптов ваши промпты **зашифрованы end-to-end** - даже OpenAI/Anthropic не может их прочитать.

```
Ваш Промпт: "Проанализировать конфиденциальные данные клиентов..."
                    ↓
           [ШИФРОВАНИЕ AES-256]
                    ↓
OpenAI видит: "llm_encrypted_v1:Jk3xQ9mL2pKq8xR5vW7yZ..."
```

## Как это работает

### 1. **Локальное Шифрование**
- Ваш код шифрует промпт ДО отправки в OpenAI/Anthropic
- Только у вас есть ключ расшифровки
- Использует **AES-256-GCM** (256-битное шифрование + аутентификация)

### 2. **Зашифрованная Отправка**
- OpenAI/Anthropic получает зашифрованный blob
- Они не могут видеть оригинальное содержимое
- Они не могут использовать ваш промпт для обучения

### 3. **Зашифрованный Ответ**
- Ответ также может быть зашифрован
- Расшифровывается локально на вашем сервере

### 4. **Открытый Исходный Код**
- Весь код доступен на GitHub
- Любой может проверить шифрование
- Нет "чёрной магии"

## Настройка

### 1. Сгенерировать Мастер-Ключ

```bash
# Linux/Mac
openssl rand -hex 32

# PowerShell
-join ((48..57) + (65..70) + (97..102) | Get-Random -Count 64 | ForEach-Object {[char]$_})
```

### 2. Добавить в .env

```env
# Ключ Шифрования Промптов (32 hex символа или любая строка)
PROMPT_ENCRYPTION_KEY=ваш-сгенерированный-ключ
```

### 3. Использовать в коде

```go
package main

import "github.com/QuantumNous/new-api/common"

func main() {
    // Создать шифровальщик
    encryptor, err := common.NewPromptEncryptor("ваш-секретный-ключ")
    if err != nil {
        panic(err)
    }

    // Зашифровать промпт
    prompt := "Это мой секретный промпт"
    encrypted, err := encryptor.EncryptPrompt(prompt)
    // encrypted = "llm_encrypted_v1:Jk3xQ9mL2pKq8xR5vW7yZ..."

    // Отправить в OpenAI
    response := callOpenAI(encrypted)

    // Расшифровать ответ
    decrypted, err := encryptor.DecryptPrompt(response)
}
```

## Техническая Спецификация

### Алгоритм
- **Cipher**: AES-256 в режиме GCM
- **Деривация Ключа**: SHA256(master_key)
- **Nonce**: 12 случайных байт (сгенерированы crypto/rand)
- **Аутентификация**: GCM обеспечивает AEAD (authenticated encryption)
- **Кодирование**: Base64

### Формат
```
llm_encrypted_v1:BASE64(nonce + ciphertext + tag)
```

### Безопасность
- ✅ **Конфиденциальность**: AES-256 военного уровня
- ✅ **Целостность**: GCM проверяет, что не было изменений
- ✅ **Подлинность**: Только тот, у кого есть ключ, может расшифровать
- ✅ **Forward Secrecy**: Если ключ скомпрометирован, старые сообщения защищены случайными nonce

## Случаи Использования

### ✅ Хорошо для шифрования:
- Промпты с персональными данными клиентов
- Финансовая информация
- Проприетарный код
- Медицинские данные
- Любая конфиденциальная информация

### ⚠️ Учитывайте:
- Стоимость шифрования (минимальная, ~1-2ms на промпт)
- OpenAI всё ещё видит, что вы звонили (метаданные)
- Если нужна максимальная конфиденциальность, рассмотрите self-hosted LLMs

Ваши промпты теперь защищены. ✅
